# CV qualification matching

The deterministic batch CV extractor filters common negated, planned and expired
claims before recognizing skills, roles, experience, education and certificates.
A generic language adjective such as "fluent" does not establish English.
A work-permit mention, question or nationality alone is not an affirmative permit
statement. This parser does not determine legal eligibility in any country.

Matching normalizes known equivalent vocabulary (M365/Microsoft 365,
Azure AD/Entra ID, Microsoft Intune/Intune, NodeJS/Node.js and named languages).
Identity administration does not automatically imply general Azure cloud or
on-premises Active Directory expertise. Unknown experience fails a minimum-year
requirement without crashing. A permitted partial match does not claim all
requirements were met.

This is conservative lexical extraction, not a general language-understanding
or credential-verification guarantee. Mixed or unusual wording can require
owner review. The original CV is retained; no new qualifications are generated.
These changes cover the deterministic batch parser, not every interpretation
made by a provider model reading a document directly.
